The Bookseller mod for Fallout Sonora
-------------------------------------

This mod adds a new vendor in Phoenix Business Center who sells skill books, which were originally absent from Fallout Sonora.

### Requirements:
* Fallout Sonora, English version (sfall repack): https://github.com/NovaRain/Fallout-Sonora-English/releases

### Installation:
1. Extract the `fs_bookseller.dat` file to the `mods` folder in the main Fallout Sonora directory.
2. If a `mods_order.txt` already exists in your `mods` folder, add **fs_bookseller.dat** on a new line.
